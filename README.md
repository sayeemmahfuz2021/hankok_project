# 🎮 Hancok – Gaming Website

A modern and visually engaging gaming website landing page designed to deliver an immersive gaming experience. Hancok combines bold visual elements, structured layouts, and gaming-inspired aesthetics to create an attractive and user-friendly interface.

## 🌐 Live Demo

🔗 **[Explore Hancok Website](https://sayeemmahfuz2021.github.io/hankok_project/)**

## 📌 Project Overview

Hancok is a gaming-focused website UI project featuring gaming communities, popular games, live streaming sections, match results, game catalogs, gaming accessories, professional teams, and FAQs.

The project focuses on building a visually appealing frontend experience while maintaining a clean structure and consistent design.

## ✨ Key Features

- Modern Gaming-Inspired UI
- Responsive Website Layout
- Gaming Community Section
- Popular Games Showcase
- Live Streaming Section
- Previous Matches Overview
- Gaming Store & Accessories
- Professional Gaming Teams
- FAQ Section
- Clean Navigation and Footer

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts
- Font Awesome Icons

## 🚀 Getting Started

To run this project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/sayeemmahfuz2021/hankok_project.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.
